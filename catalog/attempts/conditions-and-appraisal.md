# Conditions and appraisal

[All targets and attempts](../contents.md) · [Completed finite recipes](../worked-recipes.md)

The adverse route is retained from the original catalog. Beneficial variants are candidate assemblies. Named central judgments still require evidence or an implemented operation; filling every field does not guarantee benefit.

<a id="a71"></a>
## A71: Add time to reflect

**Failure or backfire route:** Reflection becomes a way to postpone a necessary decision.

**Intended beneficial effect:** Additional time produces a consequential inference or decision rather than repeated unproductive thought.

**Ingredient evidence:** No source assigned; design inference.

<a id="a71a"></a>
### A71a: Reflect on a named gap

**Use when:** One inference remains unresolved after the initial answer.

1. State the precise gap
2. Identify the premises that bear on it
3. Work through their relationship
4. Stop when the inference is resolved or its missing input is named.

**Redirect condition:** If nothing new enters the reasoning, change the input or stop.

<a id="a71b"></a>
### A71b: Return after a bounded break

**Use when:** Continued effort is repeating the same unproductive route.

1. Preserve the current state and unresolved question
2. Take a bounded break from that route
3. Return to a specified alternative representation
4. Retain any improvement that survives inspection.

**Redirect condition:** If the break yields no improvement, do not treat more waiting as a method.

<a id="a71c"></a>
### A71c: Allocate reflection by decision value

**Use when:** A choice deserves thought but not unlimited delay.

1. Identify what reflection could change
2. Estimate the cost of delay
3. Allocate time to the consequential comparisons
4. Act when the remaining uncertainty cannot justify more delay.

**Redirect condition:** If missing external evidence is decisive, seek it rather than introspecting longer.

**Linked target dimensions:** [T16: Duration of attention](../targets/attention.md#t16)

<a id="a72"></a>
## A72: Increase stimulation

**Failure or backfire route:** Excitement increases distractibility or obscures costs.

**Intended beneficial effect:** The stimulation level supports the required discrimination and sustained performance.

**Ingredient evidence:** No source assigned; design inference.

<a id="a72a"></a>
### A72a: Introduce a meaningful contrast

**Use when:** Monotony hides an important difference.

1. Identify the distinction the person misses
2. Present two sharply contrasting relevant cases
3. Direct attention to the governing difference
4. Return to the original task using that distinction.

**Redirect condition:** If surprise distracts from the distinction, remove the embellishment.

<a id="a72b"></a>
### A72b: Reduce excess stimulation

**Use when:** Additional novelty or sensory input is degrading work.

1. Identify the interfering input
2. Remove or reduce it
3. Preserve information required for the task
4. Resume from the last coherent state.

**Redirect condition:** If difficulty persists, inspect task complexity or missing knowledge.

<a id="a72c"></a>
### A72c: Change timing or setting

**Use when:** A recurring context predictably supports poor attention.

1. Identify a more workable available period or place
2. Move a bounded task there
3. Keep the task and success criterion comparable
4. Retain the change if actual performance improves.

**Redirect condition:** If moving is infeasible, reduce the task's demands within the current setting.

**Linked target dimensions:** [T13: What gets noticed](../targets/attention.md#t13), [T14: What gets ignored](../targets/attention.md#t14)

<a id="a73"></a>
## A73: Reduce interruptions

**Failure or backfire route:** Important signals are blocked along with distractions.

**Intended beneficial effect:** Necessary work receives sufficient continuity while important interruptions remain reachable.

**Ingredient evidence:** No source assigned; design inference.

<a id="a73a"></a>
### A73a: Protect a coherent work unit

**Use when:** Interruptions break a task's dependent reasoning.

1. Identify a unit that can be completed in one available interval
2. Defer nonurgent notifications for that interval
3. Keep the required inputs at hand
4. Finish or checkpoint the unit before switching.

**Redirect condition:** If urgent contact is necessary, preserve a specific channel for it.

<a id="a73b"></a>
### A73b: Capture without switching

**Use when:** Incoming thoughts or requests repeatedly redirect work.

1. Provide a simple capture location
2. Record only enough to resume later
3. Return to the current operation
4. Review captured items at a natural boundary.

**Redirect condition:** If an item changes the current task's validity, address it immediately.

<a id="a73c"></a>
### A73c: Batch routine checks

**Use when:** Frequent checking adds little immediate value.

1. Identify checks with tolerable delay
2. Select intervals matching actual urgency
3. Batch those checks
4. Revise the interval if material delays occur.

**Redirect condition:** If a stream requires immediate response, separate it from routine traffic.

**Linked target dimensions:** [T14: What gets ignored](../targets/attention.md#t14), [T16: Duration of attention](../targets/attention.md#t16), [T17: Conditions for switching attention](../targets/attention.md#t17)

<a id="a74"></a>
## A74: Change the environment

**Failure or backfire route:** A narrow cue-dependent success fails whenever the setting changes.

**Intended beneficial effect:** The environment supplies a missing condition or removes a demonstrated obstruction.

**Ingredient evidence:** No source assigned; design inference.

<a id="a74a"></a>
### A74a: Prepare the necessary resources

**Use when:** Starting fails because inputs are unavailable at the right moment.

1. List resources needed for the first action
2. Place them in the actual use setting
3. Remove a known access obstacle
4. Connect the prepared setting to the action cue.

**Redirect condition:** If readiness is already sufficient, diagnose another cause.

<a id="a74b"></a>
### A74b: Change the social conditions

**Use when:** The setting lacks real support for the intended behavior.

1. Identify the needed interaction or opportunity
2. Locate a setting where it is actually available
3. Arrange access where feasible
4. Connect the person to the relevant activity.

**Redirect condition:** If exclusion or constraints persist, do not rely on a change in interpretation alone.

<a id="a74c"></a>
### A74c: Redesign the physical sequence

**Use when:** The current arrangement repeatedly cues the wrong action.

1. Trace the usual action path
2. Identify the cue or friction that controls it
3. Reposition resources to support the endorsed action
4. Inspect behavior in the changed setting.

**Redirect condition:** If behavior does not change, reassess the assumed controlling feature.

**Linked target dimensions:** [T45: Sense of belonging](../targets/self-and-social-understanding.md#t45), [T55: Conditions that trigger starting](../targets/action-control.md#t55), [T56: Conditions that inhibit an action](../targets/action-control.md#t56), [T60: Degree of automaticity](../targets/action-control.md#t60)

<a id="a75"></a>
## A75: Reinterpret an emotion

**Failure or backfire route:** A valid warning is dismissed simply because it is emotional.

**Intended beneficial effect:** The meaning assigned to an emotion becomes more accurate or useful without denying the feeling.

**Ingredient evidence:** [S17](../sources.md#s17)

<a id="a75a"></a>
### A75a: Separate event from appraisal

**Use when:** An interpretation is being treated as an observed fact.

1. State what happened in observable terms
2. Identify the added interpretation
3. Compare alternative interpretations against the facts
4. Act on the best supported account.

**Redirect condition:** If the original appraisal is well supported, address the situation itself.

<a id="a75b"></a>
### A75b: Translate arousal into preparation

**Use when:** The person interprets ordinary task arousal as incapacity.

1. Distinguish the sensation from the capability claim
2. Identify the actual task demand
3. Choose a feasible preparation step
4. Judge readiness from performance and resources.

**Redirect condition:** If impairment is material, reduce demands rather than insisting on a positive label.

<a id="a75c"></a>
### A75c: Keep feelings from becoming evidence about unrelated claims

**Use when:** An emotional reaction is carrying an inference it cannot establish.

1. Identify the feeling and its likely trigger
2. State the separate factual question
3. Inspect evidence relevant to that question
4. Preserve the feeling as information about experience, not proof.

**Redirect condition:** If the feeling points to a real unexamined consequence, investigate that consequence.

**Linked target dimensions:** [T24: Frame used to interpret an event](../targets/representation.md#t24), [T37: Attraction or aversion](../targets/emotion-and-appraisal.md#t37), [T45: Sense of belonging](../targets/self-and-social-understanding.md#t45)

<a id="a76"></a>
## A76: Monitor one's thinking

**Failure or backfire route:** Self-observation becomes repetitive rumination.

**Intended beneficial effect:** Monitoring detects a consequential problem early enough to improve the process.

**Ingredient evidence:** No source assigned; design inference.

<a id="a76a"></a>
### A76a: Monitor a specific warning sign

**Use when:** A known reasoning failure has an observable precursor.

1. Name the failure and precursor
2. Place one check at the relevant operation
3. Inspect the precursor when it occurs
4. Invoke the corresponding repair.

**Redirect condition:** If the signal produces frequent false alarms, refine or remove it.

<a id="a76b"></a>
### A76b: Keep a minimal error record

**Use when:** Recurring errors are difficult to remember accurately.

1. Record the task, error, and consequence
2. Group comparable cases
3. Identify a repeatable cause
4. Revise one procedure that addresses it.

**Redirect condition:** If recording costs exceed the errors' significance, reduce the record.

<a id="a76c"></a>
### A76c: Review strategy at a boundary

**Use when:** Continuous self-observation would disrupt performance.

1. Choose a natural stopping point
2. Compare progress with the intended result
3. Identify a specific mismatch
4. Retain or change the strategy before the next segment.

**Redirect condition:** If performance is adequate, resume without further introspection.

**Linked target dimensions:** [T17: Conditions for switching attention](../targets/attention.md#t17), [T41: Meaning assigned to frustration](../targets/emotion-and-appraisal.md#t41), [T70: What gets monitored](../targets/self-correction.md#t70)

<a id="a77"></a>
## A77: Invite more doubt

**Failure or backfire route:** Settled matters reopen without any relevant new reason.

**Intended beneficial effect:** Doubt is directed toward a consequential uncertainty and yields proportionate revision.

**Ingredient evidence:** No source assigned; design inference.

<a id="a77a"></a>
### A77a: Reopen a controlling premise

**Use when:** A conclusion depends heavily on a weak assumption.

1. Identify that assumption
2. State what would follow if it were wrong
3. Inspect the best available contrary evidence
4. Revise the conclusion's scope or confidence accordingly.

**Redirect condition:** If the premise is well supported, retain it without manufacturing uncertainty.

<a id="a77b"></a>
### A77b: Require a reason to reopen

**Use when:** Settled issues are repeatedly reconsidered without new information.

1. Identify the original basis
2. Compare the new concern with previously addressed concerns
3. Reopen only the genuinely new premise
4. Retain the settled parts.

**Redirect condition:** If no new reason exists, move to action or another unresolved issue.

<a id="a77c"></a>
### A77c: Calibrate uncertainty

**Use when:** Certainty is inconsistent with the quality of available evidence.

1. Separate direct observations from inference
2. Identify missing or conflicting evidence
3. Adjust confidence to that evidential state
4. Specify what further evidence could change it.

**Redirect condition:** If exact probabilities are unsupported, use clearly bounded qualitative confidence.

**Linked target dimensions:** [T5: Confidence in a particular claim](../targets/knowledge-and-uncertainty.md#t5), [T11: Threshold for updating](../targets/evidence-and-trust.md#t11), [T42: Tolerance of uncertainty](../targets/emotion-and-appraisal.md#t42)

<a id="a78"></a>
## A78: Take psychological distance

**Failure or backfire route:** Detachment removes the person's own values from the decision.

**Intended beneficial effect:** Distance reveals a useful perspective while preserving the actual person's constraints and values.

**Ingredient evidence:** No source assigned; design inference.

<a id="a78a"></a>
### A78a: Advise another in the same situation

**Use when:** Self-involvement may obscure a feasible recommendation.

1. Restate the facts as another person's case
2. Preserve the same resources and obligations
3. Formulate advice
4. Translate only the applicable parts back into the present action.

**Redirect condition:** If the advice assumes advantages the person lacks, revise it.

<a id="a78b"></a>
### A78b: View the decision across time

**Use when:** Immediate salience overwhelms later consequences.

1. Specify a relevant future date
2. Describe likely consequences of each current option
3. Include what is uncertain
4. Choose with both present and later costs visible.

**Redirect condition:** If future preferences are unknown, use multiple plausible futures.

<a id="a78c"></a>
### A78c: Use neutral third-person description

**Use when:** Self-judgment is obscuring the observable sequence.

1. Describe actions and events without character labels
2. Identify the controllable transition
3. Select a repair or next move
4. Restore personally important values to the decision.

**Redirect condition:** If distance removes a material consequence, add it back.

<a id="a79"></a>
## A79: Imagine a future self

**Failure or backfire route:** An idealized future licenses neglect of present constraints.

**Intended beneficial effect:** A future-self representation changes a present choice through plausible needs and consequences.

**Ingredient evidence:** No source assigned; design inference.

<a id="a79a"></a>
### A79a: Make the future schedule concrete

**Use when:** Plans assume future time that is unlikely to exist.

1. Choose the actual future period
2. Include recurring obligations
3. Place the proposed action into available time
4. Revise the plan where capacity is exceeded.

**Redirect condition:** If the future schedule is uncertain, preserve slack rather than filling it completely.

<a id="a79b"></a>
### A79b: Carry consequences forward

**Use when:** A present choice hides predictable later burdens.

1. Identify the current convenience or benefit
2. Trace its later maintenance or repair cost
3. Compare the full sequence with an alternative
4. Choose using the endorsed time trade-off.

**Redirect condition:** If later consequences are speculative, use conditional comparisons.

<a id="a79c"></a>
### A79c: Protect enduring priorities

**Use when:** Temporary urgency displaces a repeatedly endorsed aim.

1. Identify the priority supported across contexts
2. Compare current options against it
3. Select a feasible action preserving it
4. Allow revision if the underlying value changes.

**Redirect condition:** If the priority is merely assumed, do not assign it to the person.

**Linked target dimensions:** [T32: Priorities](../targets/motivation-and-value.md#t32)

<a id="a80"></a>
## A80: Adjust the challenge

**Failure or backfire route:** The task becomes either empty repetition or unmanageable difficulty.

**Intended beneficial effect:** Challenge requires the intended skill while remaining feasible with appropriate support.

**Ingredient evidence:** [S20](../sources.md#s20)

<a id="a80a"></a>
### A80a: Repair prerequisite difficulty

**Use when:** Failure comes from a missing subskill.

1. Locate the first operation the person cannot perform
2. Teach that operation in a simpler setting
3. Demonstrate or practice it correctly
4. Return to the original task.

**Redirect condition:** If the subskill is intact, inspect integration or task demands.

<a id="a80b"></a>
### A80b: Increase one demand

**Use when:** Current performance is reliable but growth has stalled.

1. Choose one relevant demand to increase
2. Keep other demands stable
3. Provide feedback on the target operation
4. Retain the increment when performance supports it.

**Redirect condition:** If errors spread across unrelated operations, reduce the increment.

<a id="a80c"></a>
### A80c: Fit challenge to available capacity

**Use when:** Complexity or time pressure prevents useful work.

1. Identify the limiting demand
2. Reduce irrelevant complexity or pressure
3. Preserve the skill the task should exercise
4. Restore demands gradually as capacity permits.

**Redirect condition:** If simplification removes the target skill, redesign the task.
