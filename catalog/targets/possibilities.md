# Possibilities

[All targets and attempts](../contents.md) · [Status and evidence](../README.md)

These are dimensions to consider, not destinations that every inquiry must fix in advance. Each procedure below is an imported candidate outline; its checks describe the intended outcome rather than an observed result of this revision.

<a id="t25"></a>
## T25: Options considered

**Candidate improvement:** The considered set includes materially different feasible options rather than more variants of the same approach.

**Procedure outline:** Identify the current alternatives and their shared assumptions; relax one unverified restriction or combine compatible components; construct the resulting option; compare its requirements and consequences.

**Different recipes:** [A51a: Relax an assumed constraint](../attempts/decision-and-action.md#a51a); [A51b: Recombine useful parts](../attempts/decision-and-action.md#a51b); [A51c: Dissolve a false binary](../attempts/decision-and-action.md#a51c)

**Outcome check:** At least one new feasible option changes the meaningful comparison. If added options are dominated or irrelevant, do not count volume as progress.

**Ingredient evidence:** No source assigned to this outline.

<a id="t26"></a>
## T26: Counterfactuals imagined

**Candidate improvement:** Imagined alternatives reveal causal dependencies or better decisions without relying on impossible hindsight.

**Procedure outline:** Specify what changes and what stays fixed; preserve actual knowledge and feasible resources; propagate consequences through explicit assumptions; extract the condition that changes the decision.

**Different recipes:** [A27a: Change one causal input](../attempts/concepts-and-possibilities.md#a27a); [A27b: Compare feasible alternatives](../attempts/concepts-and-possibilities.md#a27b); [A27c: Test necessity and robustness](../attempts/concepts-and-possibilities.md#a27c)

**Outcome check:** The counterfactual yields a defensible lesson for a current or future case. If it requires unknowable information or impossible resources, revise it.

**Ingredient evidence:** No source assigned to this outline.

<a id="t27"></a>
## T27: Constraints believed fixed

**Candidate improvement:** Believed constraints match actual limits and available ways to alter them.

**Procedure outline:** Name the restriction; identify its physical, contractual, social, or habitual source; check whether it can be changed within actual authority; revise the feasible set accordingly.

**Different recipes:** [A26a: Release a supposedly fixed variable](../attempts/concepts-and-possibilities.md#a26a); [A51a: Relax an assumed constraint](../attempts/decision-and-action.md#a51a); [A29c: Change available resources](../attempts/concepts-and-possibilities.md#a29c)

**Outcome check:** An assumed constraint is either verified or replaced with an actually accessible alternative. Merely declaring it optional does not establish freedom.

**Ingredient evidence:** No source assigned to this outline.

<a id="t28"></a>
## T28: Actions perceived as available

**Candidate improvement:** The person recognizes actions they can actually perform with available or obtainable resources.

**Procedure outline:** Specify the desired transition; identify the first operation needed; check skill, access, and resources; supply a feasible route from the present state to that operation.

**Different recipes:** [A29b: Construct the missing path](../attempts/concepts-and-possibilities.md#a29b); [A30a: Distinguish knowing from being able](../attempts/concepts-and-possibilities.md#a30a); [A55b: Complete a prerequisite](../attempts/decision-and-action.md#a55b)

**Outcome check:** The newly perceived action can begin or has a concrete attainable prerequisite. If access remains absent, describe possibility without claiming availability.

**Ingredient evidence:** No source assigned to this outline.

<a id="t29"></a>
## T29: Directions searched

**Candidate improvement:** Search follows branches capable of producing a valuable answer or option.

**Procedure outline:** Define the result sought; identify unresolved dependencies or decision-sensitive uncertainties; choose the branch with the cheapest plausible decisive information; stop branches that cannot affect the result.

**Different recipes:** [A2a: Find the blocking dependency](../attempts/presentation-and-access.md#a2a); [A2b: Resolve decision-sensitive uncertainty](../attempts/presentation-and-access.md#a2b); [A93c: Choose the cheapest decisive operation](../attempts/optimization-and-evaluation.md#a93c)

**Outcome check:** Search produces consequential evidence or eliminates a meaningful branch at justified cost. If it only accumulates material, revise the search question.

**Ingredient evidence:** No source assigned to this outline.

<a id="t30"></a>
## T30: Estimates of feasibility

**Candidate improvement:** Feasibility estimates distinguish possibility, local accessibility, and reliable execution.

**Procedure outline:** Find a relevant existence case or constructed route; compare enabling conditions with the present situation; inspect each necessary link; estimate feasibility only within the supported conditions.

**Different recipes:** [A29a: Use a verified existence example](../attempts/concepts-and-possibilities.md#a29a); [A29b: Construct the missing path](../attempts/concepts-and-possibilities.md#a29b); [A30c: Find interacting blockers](../attempts/concepts-and-possibilities.md#a30c)

**Outcome check:** The estimate correctly identifies available and missing prerequisites. If one crucial link is unsupported, retain that uncertainty rather than averaging it away.

**Ingredient evidence:** No source assigned to this outline.
