# Decision processes

[All targets and attempts](../contents.md) · [Status and evidence](../README.md)

These are dimensions to consider, not destinations that every inquiry must fix in advance. Each procedure below is an imported candidate outline; its checks describe the intended outcome rather than an observed result of this revision.

<a id="t49"></a>
## T49: Comparison criteria

**Candidate improvement:** Comparison criteria include the features that make an option useful or unacceptable for the actual goal.

**Procedure outline:** Specify the outcome the choice should serve; identify hard requirements; add consequential preferences omitted from the comparison; evaluate only options whose required conditions hold.

**Different recipes:** [A53a: Separate constraints from preferences](../attempts/decision-and-action.md#a53a); [A24b: Restore an omitted cost](../attempts/concepts-and-possibilities.md#a24b); [A49a: Use a real trade-off](../attempts/motivation-and-value.md#a49a)

**Outcome check:** Criteria distinguish materially different options and preserve real constraints. If a criterion changes no judgment, keep it optional unless independently required.

**Ingredient evidence:** No source assigned to this outline.

<a id="t50"></a>
## T50: Weights assigned to criteria

**Candidate improvement:** Criterion weights represent the person's trade-offs over defined outcome ranges.

**Procedure outline:** Define the actual range on each criterion; compare the value of moving across those ranges; assign weights or an explicit ordinal trade-off; inspect whether plausible changes reverse the choice.

**Different recipes:** [A53b: Weight meaningful differences](../attempts/decision-and-action.md#a53b); [A53c: Locate sensitive judgments](../attempts/decision-and-action.md#a53c); [A49a: Use a real trade-off](../attempts/motivation-and-value.md#a49a)

**Outcome check:** The resulting ranking survives scrutiny of concrete sacrifices. If arbitrary scales determine the winner, repair the scales before refining the weights.

**Ingredient evidence:** No source assigned to this outline.

<a id="t51"></a>
## T51: Rule used to choose

**Candidate improvement:** The choice rule fits the task's constraints, uncertainty, and consequences.

**Procedure outline:** Eliminate unacceptable options; compare the remaining relevant consequences; choose a rule appropriate to the available information and endorsed trade-offs; state the circumstances that would change its recommendation.

**Different recipes:** [A53a: Separate constraints from preferences](../attempts/decision-and-action.md#a53a); [A53c: Locate sensitive judgments](../attempts/decision-and-action.md#a53c); [A87b: Give the supported verdict](../attempts/conversation-and-joint-work.md#a87b)

**Outcome check:** The rule yields an acceptable justified choice on the live problem. A numeric score is not required when robust dominance or a simple constraint resolves the decision.

**Ingredient evidence:** No source assigned to this outline.

<a id="t52"></a>
## T52: Balance of exploration and commitment

**Candidate improvement:** Exploration continues only while its expected decision benefit warrants its cost, and commitment remains revisable.

**Procedure outline:** Identify what is still unknown; locate information capable of changing the decision; compare its attainable value with delay and effort; explore or commit with an explicit revision condition.

**Different recipes:** [A93c: Choose the cheapest decisive operation](../attempts/optimization-and-evaluation.md#a93c); [A59b: Stop when information cannot change the choice](../attempts/decision-and-action.md#a59b); [A58c: Commit to a decision rule](../attempts/decision-and-action.md#a58c)

**Outcome check:** The person gathers consequential information and acts when enough is available. If exploration cannot alter the choice, move to execution; if new evidence invalidates it, reopen.

**Ingredient evidence:** No source assigned to this outline.

<a id="t53"></a>
## T53: Threshold for accepting an option

**Candidate improvement:** Acceptance uses a stated sufficient standard appropriate to actual costs and alternatives.

**Procedure outline:** Define essential requirements and a worthwhile outcome; compare feasible options with that standard; account for the cost of waiting for improvement; accept a sufficient option or revise an infeasible standard.

**Different recipes:** [A53a: Separate constraints from preferences](../attempts/decision-and-action.md#a53a); [A52b: Use a reversible default](../attempts/decision-and-action.md#a52b); [A59b: Stop when information cannot change the choice](../attempts/decision-and-action.md#a59b)

**Outcome check:** An accepted option meets the intended need at justified cost. If standards fall merely to excuse failure, preserve the original result and record the changed goal separately.

**Ingredient evidence:** No source assigned to this outline.

<a id="t54"></a>
## T54: Rule for stopping deliberation

**Candidate improvement:** Deliberation ends under a valid completion or resource rule rather than fatigue, ritual, or pressure alone.

**Procedure outline:** Specify the decision and sufficient evidence; identify remaining reversal conditions; obtain worthwhile discriminating information; stop when the conclusion is complete or further inquiry is not justified.

**Different recipes:** [A59a: Stop after logical completion](../attempts/decision-and-action.md#a59a); [A59b: Stop when information cannot change the choice](../attempts/decision-and-action.md#a59b); [A59c: Stop a failing route](../attempts/decision-and-action.md#a59c)

**Outcome check:** Stopping preserves a supported action and explicit unresolved limits. If a decisive prerequisite is absent, report conditional completion or a provisional action.

**Ingredient evidence:** No source assigned to this outline.
