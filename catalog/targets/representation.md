# Representation

[All targets and attempts](../contents.md) · [Status and evidence](../README.md)

These are dimensions to consider, not destinations that every inquiry must fix in advance. Each procedure below is an imported candidate outline; its checks describe the intended outcome rather than an observed result of this revision.

<a id="t19"></a>
## T19: Distinctions

**Candidate improvement:** A distinction separates cases that require different inferences or actions.

**Procedure outline:** Choose a currently confused pair; isolate the consequential differing feature; derive why it changes the result; apply the distinction to a new case.

**Different recipes:** [A65a: Construct a minimal pair](../attempts/learning-and-memory.md#a65a); [A8b: Split an overloaded term](../attempts/presentation-and-access.md#a8b); [A6a: Construct a minimal pair](../attempts/presentation-and-access.md#a6a)

**Outcome check:** The person handles a near-match correctly and can state the governing difference. If only the label is learned, return to the contrast.

**Ingredient evidence:** [S12](../sources.md#s12), [S13](../sources.md#s13)

<a id="t20"></a>
## T20: Categories

**Candidate improvement:** Categories support reliable recognition without erasing material exceptions.

**Procedure outline:** Collect representative members and neighboring nonmembers; identify the governing features or relations; compare mixed cases; retain exceptions affecting use.

**Different recipes:** [A63b: Interleave confusable cases](../attempts/learning-and-memory.md#a63b); [A23c: Unify with exceptions](../attempts/concepts-and-possibilities.md#a23c); [A65c: Defeat a misleading resemblance](../attempts/learning-and-memory.md#a65c)

**Outcome check:** Unseen cases are classified accurately at the required scope. If surface resemblance dominates, compare structurally matching and misleading examples.

**Ingredient evidence:** [S13](../sources.md#s13)

<a id="t21"></a>
## T21: Boundaries

**Candidate improvement:** Boundaries specify where a claim, category, or procedure changes validity.

**Procedure outline:** Write the current rule; locate cases on either side of its proposed limit; identify the condition responsible; express the boundary and unresolved borderline region.

**Different recipes:** [A65b: Locate a boundary](../attempts/learning-and-memory.md#a65b); [A17b: Repair the boundary](../attempts/evidence-and-inference.md#a17b); [A5b: Expose a boundary](../attempts/presentation-and-access.md#a5b)

**Outcome check:** Near-boundary cases receive the appropriate rule or uncertainty. If the boundary is conventional, success means using the convention accurately, not discovering a natural law.

**Ingredient evidence:** No source assigned to this outline.

<a id="t22"></a>
## T22: Level of detail

**Candidate improvement:** Detail matches the operation the person needs to perform.

**Procedure outline:** Specify that operation; identify information required to perform it correctly; remove redundant detail; restore any missing premise or exception that changes the result.

**Different recipes:** [A4c: Separate the usable core from detail](../attempts/presentation-and-access.md#a4c); [A5a: Repair a missing inference](../attempts/presentation-and-access.md#a5a); [A97c: Separate core from recoverable detail](../attempts/optimization-and-evaluation.md#a97c)

**Outcome check:** The representation supports the intended inference or action with lower effort. If compression changes the result, restore the lost distinction.

**Ingredient evidence:** No source assigned to this outline.

<a id="t23"></a>
## T23: Connections among ideas

**Candidate improvement:** Connections among ideas support justified inference and transfer.

**Procedure outline:** Align the functional roles across ideas; identify a shared relation or dependency; distinguish analogy from established causation; apply the connection to a new relevant problem.

**Different recipes:** [A7a: Map relationships explicitly](../attempts/presentation-and-access.md#a7a); [A23a: Extract a relation](../attempts/concepts-and-possibilities.md#a23a); [A64b: Expose an invariant](../attempts/learning-and-memory.md#a64b)

**Outcome check:** A new inference follows correctly and the connection's limits remain visible. If only thematic similarity exists, label the association without treating it as evidence.

**Ingredient evidence:** [S12](../sources.md#s12)

<a id="t24"></a>
## T24: Frame used to interpret an event

**Candidate improvement:** The interpretive frame preserves facts and values while exposing a useful implication.

**Procedure outline:** State the observed event separately from interpretation; construct a frame that changes the unit, relation, or assumed purpose; check it against the same facts and constraints; use its valid new implication.

**Different recipes:** [A21a: Preserve the result, replace the formulation](../attempts/concepts-and-possibilities.md#a21a); [A21b: Change the unit of intervention](../attempts/concepts-and-possibilities.md#a21b); [A75a: Separate event from appraisal](../attempts/conditions-and-appraisal.md#a75a)

**Outcome check:** The frame changes a warranted explanation or feasible action. If it merely feels better while hiding a cost, reject or narrow it.

**Ingredient evidence:** [S17](../sources.md#s17)
