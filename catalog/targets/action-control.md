# Action control

[All targets and attempts](../contents.md) · [Status and evidence](../README.md)

These are dimensions to consider, not destinations that every inquiry must fix in advance. Each procedure below is an imported candidate outline; its checks describe the intended outcome rather than an observed result of this revision.

<a id="t55"></a>
## T55: Conditions that trigger starting

**Candidate improvement:** A recognizable opportunity triggers an endorsed action that is feasible at that moment.

**Procedure outline:** Verify value and feasibility first; identify a reliable event or time; specify the first observable action; place the cue and required resources at that use point.

**Different recipes:** [A54a: Connect a cue to an available action](../attempts/decision-and-action.md#a54a); [A55a: Specify the first physical operation](../attempts/decision-and-action.md#a55a); [A74a: Prepare the necessary resources](../attempts/conditions-and-appraisal.md#a74a)

**Outcome check:** The action begins when the cue occurs under its valid conditions. If it does not, distinguish a missed cue from absent resources or a goal the person does not endorse.

**Ingredient evidence:** [S23](../sources.md#s23), [S15](../sources.md#s15)

<a id="t56"></a>
## T56: Conditions that inhibit an action

**Candidate improvement:** An action is inhibited when its validity conditions fail, without blocking worthwhile alternatives.

**Procedure outline:** Identify the harmful or invalid action condition; choose a detectable precursor; attach a feasible pause or alternative response; preserve the route for valid cases.

**Different recipes:** [A54c: Include a stop or revision branch](../attempts/decision-and-action.md#a54c); [A58b: Use a chosen constraint](../attempts/decision-and-action.md#a58b); [A74c: Redesign the physical sequence](../attempts/conditions-and-appraisal.md#a74c)

**Outcome check:** The person avoids the targeted action under the specified condition and can still act appropriately elsewhere. If inhibition generalizes too far, narrow the cue.

**Ingredient evidence:** No source assigned to this outline.

<a id="t57"></a>
## T57: Sequence of actions

**Candidate improvement:** The action sequence respects prerequisites, interfaces, and the cost of propagating errors.

**Procedure outline:** Define the required output; map dependencies and handoffs; place consequential checks before costly commitments; execute and recombine compatible outputs in order.

**Different recipes:** [A56a: Order by prerequisites](../attempts/decision-and-action.md#a56a); [A56b: Place a consequential checkpoint](../attempts/decision-and-action.md#a56b); [A22c: Preserve interactions](../attempts/concepts-and-possibilities.md#a22c)

**Outcome check:** The sequence produces the specified result. If every step is completed but the result fails, inspect the recipe's causal sufficiency rather than declaring success.

**Ingredient evidence:** No source assigned to this outline.

<a id="t58"></a>
## T58: Persistence

**Candidate improvement:** Persistence continues while the goal remains valuable and the route shows justified progress.

**Procedure outline:** State the endorsed purpose; identify a meaningful progress signal; remove a demonstrated obstacle; continue only within predeclared value, progress, and resource conditions.

**Different recipes:** [A58a: Protect a priority](../attempts/decision-and-action.md#a58a); [A59c: Stop a failing route](../attempts/decision-and-action.md#a59c); [A30c: Find interacting blockers](../attempts/concepts-and-possibilities.md#a30c)

**Outcome check:** Effort survives ordinary interruption but stops or redirects when continuation loses value. Mere endurance cannot establish beneficial persistence.

**Ingredient evidence:** [S8](../sources.md#s8)

<a id="t59"></a>
## T59: Conditions for changing course

**Candidate improvement:** Course changes respond to consequential new evidence, failed prerequisites, or changed goals.

**Procedure outline:** Record the current route and rationale; identify observable conditions invalidating it; specify the feasible alternative response; invoke that response when the condition occurs.

**Different recipes:** [A54c: Include a stop or revision branch](../attempts/decision-and-action.md#a54c); [A58c: Commit to a decision rule](../attempts/decision-and-action.md#a58c); [A95b: Detect changed circumstances](../attempts/optimization-and-evaluation.md#a95b)

**Outcome check:** The route changes when warranted and remains stable under irrelevant noise. If an unanticipated premise fails, reopen the rule rather than demanding an exact listed trigger.

**Ingredient evidence:** No source assigned to this outline.

<a id="t60"></a>
## T60: Degree of automaticity

**Candidate improvement:** A useful behavior requires less deliberate initiation in a stable setting while remaining interruptible when inappropriate.

**Procedure outline:** Choose a worthwhile repeatable action; bind it to a stable recognizable context; make repeated execution feasible; monitor reduced effort separately from frequency and continued appropriateness.

**Different recipes:** [A54a: Connect a cue to an available action](../attempts/decision-and-action.md#a54a); [A74c: Redesign the physical sequence](../attempts/conditions-and-appraisal.md#a74c); [A63c: Revisit at actual use points](../attempts/learning-and-memory.md#a63c)

**Outcome check:** The action becomes easier to initiate across repeated opportunities. No fixed number of days certifies automaticity; if context changes, rebuild the cue or retain deliberate control.

**Ingredient evidence:** [S16](../sources.md#s16)
