# Evidence and trust

[All targets and attempts](../contents.md) · [Status and evidence](../README.md)

These are dimensions to consider, not destinations that every inquiry must fix in advance. Each procedure below is an imported candidate outline; its checks describe the intended outcome rather than an observed result of this revision.

<a id="t7"></a>
## T7: Reliability assigned to a source

**Candidate improvement:** Reliance on a source tracks relevant accuracy and independence rather than prestige or familiarity.

**Procedure outline:** Identify the exact claim being entrusted; inspect relevant expertise and original evidence; check independent corroboration where consequential; assign reliance at that claim's scope.

**Different recipes:** [A31a: Scope expertise](../attempts/trust-and-social-relations.md#a31a); [A31b: Corroborate independently](../attempts/trust-and-social-relations.md#a31b); [A16c: Trace a citation chain to origin](../attempts/evidence-and-inference.md#a16c)

**Outcome check:** Trust distinguishes supported from unsupported claims by the same source. If overall liking changes alone, source calibration has not been demonstrated.

**Ingredient evidence:** [S10](../sources.md#s10)

<a id="t8"></a>
## T8: Scope of a source's expertise

**Candidate improvement:** Expertise is neither generalized beyond its domain nor dismissed within it without reason.

**Procedure outline:** Specify the task requiring expertise; compare it with the source's actual demonstrated work; identify transferable and missing competencies; seek another source for consequential gaps.

**Different recipes:** [A31a: Scope expertise](../attempts/trust-and-social-relations.md#a31a); [A16b: Audit the source's applicability](../attempts/evidence-and-inference.md#a16b); [A31c: Use a relevant track record](../attempts/trust-and-social-relations.md#a31c)

**Outcome check:** A new out-of-domain claim receives different scrutiny from an in-domain claim. If no relevant record exists, preserve uncertainty rather than manufacture a rating.

**Ingredient evidence:** No source assigned to this outline.

<a id="t9"></a>
## T9: Trust in a method

**Candidate improvement:** Trust in a method depends on its operating conditions, comparative results, and failure modes.

**Procedure outline:** Define the result the method promises; inspect evidence in comparable settings; distinguish completion from effect; specify when to use, adapt, or reject the method.

**Different recipes:** [A95a: Match the causal conditions](../attempts/optimization-and-evaluation.md#a95a); [A95b: Detect changed circumstances](../attempts/optimization-and-evaluation.md#a95b); [A83c: Stress the execution path](../attempts/conversation-and-joint-work.md#a83c)

**Outcome check:** A method is retained after relevant success and revised when its premises fail. One satisfying outcome does not establish general reliability.

**Ingredient evidence:** [S15](../sources.md#s15), [S20](../sources.md#s20), [S23](../sources.md#s23)

<a id="t10"></a>
## T10: Trust in one's own judgment

**Candidate improvement:** Self-trust becomes domain-specific and responsive to actual performance.

**Procedure outline:** Identify the class of judgments; compare past confidence with independently resolved outcomes; separate skill from favorable circumstances; adjust reliance and verification for this task class.

**Different recipes:** [A46b: Calibrate confidence](../attempts/motivation-and-value.md#a46b); [A46a: Use representative mastery evidence](../attempts/motivation-and-value.md#a46a); [A94a: Observe transfer](../attempts/optimization-and-evaluation.md#a94a)

**Outcome check:** Appropriate independent action and selective checking improve together. If confidence rises without relevant evidence, use representative performance before reassurance.

**Ingredient evidence:** [S11](../sources.md#s11), [S2](../sources.md#s2)

<a id="t11"></a>
## T11: Threshold for updating

**Candidate improvement:** The threshold for revising a claim reflects evidence strength; the threshold for acting also reflects consequences.

**Procedure outline:** Separate belief revision from action choice; specify what evidence would materially change support; specify which support level would change action under the person's priorities; update each threshold for its own reason.

**Different recipes:** [A28c: Find the decision boundary](../attempts/concepts-and-possibilities.md#a28c); [A77a: Reopen a controlling premise](../attempts/conditions-and-appraisal.md#a77a); [A53c: Locate sensitive judgments](../attempts/decision-and-action.md#a53c)

**Outcome check:** New evidence can change confidence without forcing action, and changed stakes can change action without altering factual belief. If these are conflated, separate them explicitly.

**Ingredient evidence:** No source assigned to this outline.

<a id="t12"></a>
## T12: Willingness to verify

**Candidate improvement:** Verification is used where it can prevent a meaningful error at reasonable cost.

**Procedure outline:** Identify the decision-sensitive claim; estimate the consequence of error; locate the cheapest sufficiently independent check; verify and use the result before the costly commitment.

**Different recipes:** [A56b: Place a consequential checkpoint](../attempts/decision-and-action.md#a56b); [A93c: Choose the cheapest decisive operation](../attempts/optimization-and-evaluation.md#a93c); [A16a: Bind each consequential claim to support](../attempts/evidence-and-inference.md#a16a)

**Outcome check:** The check changes or supports the decision on new evidence. If it cannot affect the result, remove it unless a required gate independently justifies it.

**Ingredient evidence:** No source assigned to this outline.
