# Dimensions that the original target list does not organize well

These are additional distinctions revealed by the audit. Some overlap existing targets; their value is the new question they permit, not an inflated count of supposedly independent mental faculties.

| What can change | Why it is not captured by changing a factual answer alone | Present consequence |
|---|---|---|
| The question being pursued | Accurate answers to an inferior question can still waste the opportunity | Exploration can discover the question and destination. |
| The interpretation of an instruction | An executor may mistake a metaphor or design ambition for an already specified experiment | Recipe reliability is treated as a construction problem as well as an empirical claim. |
| Which instructions are treated as binding | An assistant-created template can be obeyed as if the user required it | Fixed recipe lengths and universal fixed-target entry conditions are removed. |
| The set of possible situations admitted | A selector can fail by excluding the true causal model before reasoning begins | Equal confidence and partial dependence retain compatible alternatives. |
| The allowed operations | Knowing the right destination does not make it reachable | An impossible allowed path requires changed capability or a changed constraint, not better wording. |
| What counts as a result | A schema, operation, completed deduction, and human effect answer different questions | The front page leads with consequences, and the old schema-level PASS is corrected. |
| The unit of comparison | Per-sentence value can miss a useful sequence; aggregate rates can hide complete subgroup failure | Evaluate the relevant sequence and population before transferring a verdict. |
| The time horizon | Immediate fluency, later recall, enduring interest, and a vanishing opportunity need different observations | Existing observations retain their time scope; timing deductions include option expiry. |
| The source of a judgment | Two displayed confirmations can be one observation | The new alarm formula retains dependence instead of interpolating between two convenient cases. |
| The meaning of success or benefit | A worthwhile changed criterion can alter how the same outcome should be evaluated | Historical C0 verdicts remain identifiable when a current C1 evaluation is added. |
| The value of the activity itself | Curiosity or expression may be the goal, with no later instrumental payoff required | The XOR classification is retained on its mathematical merits. |
| The representation used to retrieve a finding | Preserved bytes can still be inaccessible through broken navigation | Native paths and several linked views replace archive-only access as the primary organization. |

These dimensions interact with the 72 targets. They should be available as cross-cutting views, rather than forcing every future discovery into one exclusive hierarchy.
