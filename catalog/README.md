# Mind-change targets and candidate recipes

This is the separately requested recipe catalog, preserved alongside the [larger 616-entry contributor inventory](../mind-change/targets.md) and [25 inquiries](../inquiries/perspective-25/README.md): 72 target dimensions, 100 attempt types with adverse routes, and 300 beneficial recipe variants. Every imported entry is retained. The [original document](original/mind-change-science.md) preserves the supplied artifact exactly; the views below are generated from [one editable data file](data.json).

The original called these variants executable recipes too broadly. They contain useful sequences, but operations such as identifying the relevant cause or selecting an adequate mechanism can still be unresolved judgments. The [audit](../revision/intent-audit.md) corrects that claim. The [completed finite recipes](worked-recipes.md) supply actual inputs, calculations, outputs, and guarantees where the necessary model is available. The [reliability result](../findings/reliability-and-benefit.md) derives what would be required to extend a guarantee to beneficial human effects.

Use a target view to explore what might change, including motivation, interest, interpretation, and criteria. Use an attempt view to inspect different candidate recipes and backfire routes. Use a completed finding when it already settles the question. A target need not be fixed before exploring it.

There is no required number of variants or steps in the active format. Three variants and four semicolon-separated steps per variant describe the imported version, not a standard of adequacy. Ingredient citations do not validate an assembled recipe; 26 attempt cards cite ingredients and 74 currently do not. The [source notes](sources.md) preserve the stated evidence boundaries. A proposed adverse route also remains a hypothesis unless the attached evidence demonstrates it.

See [the generated contents](contents.md) and [dimensions that cross the original taxonomy](beyond-the-original-taxonomy.md).

Edit data.json and run `python tools/render_catalog.py` to rebuild the views. This checks references and renders content; it does not certify efficacy or semantic completeness.
