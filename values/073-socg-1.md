# Silence after a proposal has several social positions

Application: 073-socg-1. Actor: this assistant's current working model and generated artifacts unless a constructed case is explicitly identified. Human outcomes are not observed.

Starting working judgment: In a constructed planning meeting, I initially treated a quiet reviewer as weak evidence of low interest; no access or speaking-opportunity facts had yet been separated.

Source: ../sources/values-socg.md. Requirements receipt: ../sources/values-socg.receipt.txt. Original loaded through read_original.py; byte checks are recorded separately in source-integrity.json.

Depth: The original specifies no numerical 8x scaling. All presently executable stages are addressed; unavailable live stages are recorded separately. Expanded scope is stated rather than inventing an 8x certification. Four perspectives, five silence hypotheses, two action/reaction sequences, eight leverage points, and a later transcript classification.

Social setting: a fictional team choosing an exhibition layout. Players: A proposer can change the design; B reviewer sees only a low-resolution image; C coordinator controls the meeting agenda; D installer knows the room dimensions. History: one draft was circulated, and B has not commented. Formal power belongs to C over the decision slot; A has informal ownership; D has unique feasibility information.

Stated layer: “Any objections to layout two?” and silence from B. Unstated candidates remain hypotheses: B agrees; B is uninterested; B cannot inspect the image; B believes C has already decided; B is waiting for D’s dimensions. The known low-resolution access specifically supports incomplete information. No private emotional state is invented.

Perspective models:

| Player | Wants / fear / belief | Sees other roles | Constraint and emotion status |
|---|---|---|---|
| A | Test a distinctive layout / lose design coherence / silence looks encouraging | B as reviewer, C as decider | Needs feedback; feeling unknown |
| B | Evaluate legibility / approve something unseen / image unreadable at available resolution | A owns design; C owns time | Cannot inspect detail; feeling unknown |
| C | End with feasible choice / meeting overruns / participants have draft | A presents; B/D respond | Decision slot limited; feeling unknown |
| D | Build workable layout / unsafe fit / room dimensions constrain options | A’s draft provisional | Needs dimensions considered; feeling unknown |

Reaction comparison: if C declares approval from silence, A treats layout as settled, B has no factual basis to endorse it, and D’s later constraint becomes an apparent reversal. If C first shares readable detail and asks D for the specific dimension, B can produce a reviewable objection or assent. A’s reaction to a late objection would then concern content, not a supposed broken agreement. These are conditional predictions, not observed emotions.

Eight social leverage points: readable common input; explicit distinction between proposal and decision; one invitation per expertise domain; B’s option to withhold judgment; D’s dimension before final choice; A’s ability to name what is artistically non-negotiable; C’s clear decision authority; a correction route after meeting. Highest-impact lever in this case is common access to the proposal because without it B cannot perform the requested review.

Move generated: “Before calling this approved, here is the readable layout. D, which dimension constrains installation? B, please separate what you can assess now from what remains unclear.” Tone is direct and invitational. Sequence: common input, relevant constraint, review, decision. Audience is the existing team; no message is sent. Risks: over-questioning delays a settled decision; mitigation is one specific access check. Fallback: mark B’s review unresolved rather than infer assent.

Certificate: the known unreadable input provides an information explanation that the low-interest hypothesis lacks. It does not prove interest; it defeats using silence alone as evidence for a settled preference. The second-order consequence is concrete: premature approval converts later information into apparent social inconsistency.

Subsequent application, executed: New constructed transcript: chair says “Everyone agreed yesterday”; member replies “I was not invited to that channel.” Initial consensus summary would list that member as agreeing from absence of objection. Applying the perspective map produces “participants in yesterday’s channel agreed; this member’s position is unresolved.” The actual generated consensus record now fits the explicit participation fact and does not require a human motive guess.

Actual mind change: The generated social move now checks participation opportunity and shared information before assigning meaning to silence.

Benefit: In a distinct later transcript, the revised classifier preserves an absent stakeholder’s unresolved position instead of adding them to a consensus.

Verdict: KEEP
