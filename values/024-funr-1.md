# A museum of questions nobody has answered

Application: 024-funr-1. Actor: this assistant's current working model and generated artifacts unless a constructed case is explicitly identified. Human outcomes are not observed.

Starting working judgment: I initially represented a question primarily as a request for an answer; a useful archive therefore seemed to consist of answers and unresolved answer slots.

Source: ../sources/values-funr.md. Requirements receipt: ../sources/values-funr.receipt.txt. Original loaded through read_original.py; byte checks are recorded separately in source-integrity.json.

Depth: The original specifies no numerical 8x scaling. All presently executable stages are addressed; unavailable live stages are recorded separately. Expanded scope is stated rather than inventing an 8x certification. Five hooks, eight dependent pulls, three tangents, three counterfactual experiments, a dead end, and a distinct later prompt.

Subject: a museum whose exhibits are questions, including questions that have never had an answer. Curiosity hooks: a museum preserves objects but questions point away from themselves; an unanswered question can outlive its asker; a label can spoil an exhibit by explaining it; an empty pedestal can attract attention; two visitors can leave with incompatible good questions.

Thread: what does a question exhibit contain?

Pull 1: an answer cannot be the defining exhibit because the museum includes unanswered questions. Finding: the exhibit must preserve the conditions that make the question noticeable.
Pull 2: what survives if words are removed? Finding: a door handle mounted on a blank wall asks about absent access without a sentence.
Pull 3: what if the wall is removed? Finding: the same handle becomes an ordinary spare part; the question lived in the relation, not the object alone.
Pull 4: what if the visitor has never seen a door? Finding: the handle/wall contrast no longer carries the same question; shared expectations are part of the exhibit.
Pull 5: could two objects ask the same question? Finding: a clock with thirteen equal marks and a staircase ending at a window both invite “which expectation did I supply?” despite different surfaces.
Pull 6: could one object ask opposed questions? Finding: the staircase can invite escape or confinement depending on which side is accessible; the exhibit needs a viewpoint.
Pull 7: what would a catalogue preserve? Finding: object, relation, expected norm, and viewing position—not merely an interrogative sentence.
Pull 8: what if an answer restores the ordinary relation? Finding: “the wall was moved yesterday” closes one historical question but leaves a new design question: why keep the handle? The exhibit can survive one answer by changing what it asks.

Tangents: a weather report for discarded questions; a cloakroom that returns a different uncertainty; an audio guide that asks the visitor to invent its missing last sentence. They are retained for pure interest; no immediate payoff is assigned.

What-if experiments: reverse the museum rule so answers must enter disguised as objects → a label becomes contraband; remove visitors → unresolved questions remain descriptions with no enacted viewpoint; combine museum and rehearsal room → exhibits can be rearranged and ask different questions tomorrow. The last hybrid connects inquiry to staging: relational position determines which contrast is available. This is a constructed analogy, not a psychological law.

Dead end: ranking exhibits by strangeness gives no principled distinction between a fresh question and random nonsense. It dies there; obscurity alone supplies no relation to inspect.

Discovery: an exploratory prompt can specify a violated expectation and a viewpoint before asking for an answer. Updated representation: question = answer request OR attention arrangement. Further exploration: yes, test the second representation on an ordinary social scene.

Subsequent application, executed: New constructed scene: a colleague repeatedly closes a shared office door. Answer-request prompt: “Why do they dislike collaboration?” Revised attention arrangement: “From the corridor the closed door removes access; from the desk it removes noise. Which access expectation and work constraint are known in this case?” The produced output now contains two information-dependent interpretations and requests the missing fact. The initial motive-loaded question would have selected dislike as its premise. This is a local representation improvement, not evidence about the colleague.

Actual mind change: I added “attention arrangement” as a question representation, with relation, expectation, and viewpoint fields.

Benefit: The subsequent social prompt distinguishes two plausible interpretations without imputing either to a real person.

Verdict: KEEP

Organization: The content gain is a new prompt form, not general proof that museums improve thinking. Organization stores the prompt’s relation and viewpoint so the surprising part survives its wording.

Next attempts: Build a sound-only question exhibit; use an ordinary object with no novelty; test a prompt whose apparent question disappears when viewpoint changes.
