Constructed input: an actor reports saying yes to optional group tasks before inspecting time and scope, then withdrawing. Break mode. Exact behavior to interrupt: immediate acceptance of an undefined task. Current pattern is stipulated; real user history is not used. Desired behavior: acknowledge the request, identify its scope and deadline, then make an honest choice.

Cue: a new optional task request addressed to the actor. Reliability: situational, not daily. Current routine: “Sure” before task definition. Underlying-need hypotheses: maintain connection, avoid silence, help the group, appear reliable. They are not elicited intrinsic values. Replacement: “What is the deliverable and deadline? I can decide once those are clear.” This can still end in yes.

Minimum: one scope question. Full: compare the defined task with actual commitments, answer yes/no/alternative, and record the accepted boundary. Immediate reward candidate: relief from an undefined promise, unobserved. Tracking mark means “defined before accepted,” not “became assertive.” Identity link is proposed as reliable contributor, not a fixed self-definition.

Eight obstacles: public pressure → ask the same brief factual question; genuine emergency → state what can be done now; vague answer → no acceptance implied; request already clear → choose directly; fear of seeming unhelpful → offer a bounded contribution if wanted; repeated request → reference the prior boundary; existing promise → honor or renegotiate explicitly; a quick easy task → no artificial delay needed. Recovery: if an undefined yes occurred, clarify promptly rather than preserve an image of perfect streak.

Environment: a visible “deliverable / deadline / owner” line beside incoming tasks; no extra barrier for clearly understood requests. Make automatic yes less immediate by drafting the scope question first, not by imposing punishment. Accountability: voluntary self-review after several actual requests; social partner only if chosen.

Measurement: proportion of optional requests defined before acceptance; later withdrawals; whether accepted work is completed. Interest in collaboration and interpersonal acceptance remain different outcomes. Review after five real opportunities, not elapsed days. Adjustment trigger: the replacement becomes an excuse never to help or creates unnecessary questioning for already clear tasks.

Later application: constructed request “Can you help with the exhibition?” gets a scope question; “Can you label these three replica boxes by 4?” gets a direct bounded acceptance in the generated dialogue. This demonstrates a conditional replacement, not a changed human habit.

Actual mind change: The replacement is a scope-sensitive choice rather than an automatic refusal. The recurring human effect is untested.

Benefit: The constructed dialogue preserves helpfulness and honest commitment boundaries.
