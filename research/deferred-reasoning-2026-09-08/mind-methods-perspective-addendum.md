The decisive finding is an actual failure to propagate a correction into its producer. `methods/gg-02-araw.md` lines 31–34 and 152 describe a repair from an incomplete capsule with a generic next operation to a capsule with the full input and a specific SP-02 operation. The current saved capsule confirms that repair. But the retained `methods/gg_checks.py` still writes the old generic operation directly over `resumption-capsule.json` and then replaces the expanded observation record with its earlier weaker format.

This was executed with the generator's output directory redirected to a new temporary directory; the extracted repository and original files were untouched. The repaired operation was a structured object identifying a skill, application, exact input, source and hash. Replaying the retained producer replaced it with “inspect the first incomplete dependency and execute a ready independent slot.” The input contracted from 374 to 203 characters, and 13 repaired observation fields disappeared. `mind-methods-gg-regression-result.json` preserves the exact result.

The conclusion is stronger than “a later model might ignore the correction.” The stored producer deterministically reinstates the defect when run. The repair changed an output, while the unchanged generating operation still defines how that output is reproduced. A correction in a dependent artifact is not a correction to the generating system. The relevant prevention is maintaining the correction in the authoritative producing transformation; adding another declaration against vague next steps cannot fix this mechanism.

The capsule explicitly lists changed source bytes as an invalidation condition, so the correct present result is “source re-examination required before relying on the old state,” not “the capsule guarantees correct replay” or “all retained context is useless.” This audit establishes a real later read and a real version mismatch, not merely the possibility of either.

There is a smaller definite logical misclassification in GG-02 ARAW. C13 at line 99 says preconditions must hold **at execution**. F62 at line 101 is labeled an “AW same-scope countercase,” but describes a trigger handler obtaining the source before the dependent act. That satisfies C13: the precondition holds when consumed. The registry at line 172 then contrasts the consuming-act reading with an initial-trigger-time reading that C13 never asserted. The alleged counterexample therefore changes the proposition under test. The distinction between trigger readiness and dependent-action readiness is useful, but this example cannot be credited as refuting the original condition. It illustrates performative opposition: a countercase label is present while the logical relation required by that label is absent.

- PCI-01/02 honestly distinguish Gold under a local field schema from semantic correctness. They remain UNRESOLVED for additional benefit and record downstream ITERATE use that found behavior missing despite Gold. A named tier is not automatically performative when its restricted meaning is preserved.
- UPTH-01 constructs and uses a three-step creative operation, while explicitly keeping human expert and newcomer stages partial. A performed local transformation and an unperformed human validation can coexist without either standing in for the other.
- ADEP-01 explicitly marks profile questions, user ratings, diverse sampling and downstream extraction as unavailable. Its completed artifact is a 50-item content-sample manifest. This is unfinished execution of the full original procedure, but not a false claim of calibration or a reason to block independent work.
- MTCG-02 supplies a necessary-and-sufficient XOR reachability criterion and executable witness words. Its symbols are defined mathematical variables, not semantic placeholders. It derives and uses the result on changed inputs rather than instructing a later actor to find the invariant.

The broader lesson from this subset is that truthful incompleteness is better than counterfeit completion but does not itself complete an unfinished assignment. Conversely, a future-facing sentence is not evidence of abandonment when a concrete dependent artifact performs its operation. The audit must follow the actual dependency and producer paths. The GG regression shows why this matters: the polished narrative describes the correction accurately, yet the retained production path still reconstructs the defective version.
