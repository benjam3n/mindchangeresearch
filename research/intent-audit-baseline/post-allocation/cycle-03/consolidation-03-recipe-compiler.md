# Consolidation 03 — transition recipe compiler

Intended mind change: Replace skill or message selection as the first operation with one compact compiler that routes an intended mind change through admissibility, locus, transition shape, execution capability, and the correct success witness.

Actual starting judgment: The candidate compiler appeared more reusable than retrieving four source findings, but the cases and comparison criteria were frozen first in `consolidation-03-freeze.md`.

Concrete input: four established findings, four fixed cases C1–C4, two nonapplication boundaries C5–C6, and six frozen comparison criteria.

## Four retained findings

1. Noncompensatory value conflict by field transformation: serve privacy and auditability by transforming content, identity, route, authority, and expiry separately; do not let one value compensate for a hard boundary on another field.
2. Typed two-stage belief transition: select state variable, locus, criterion, and admissibility constraints before evidence; let evidence determine epistemic direction; record action separately.
3. Unchanged output does not identify the mind-change locus: identical nonpublication can arise from belief, permission, motivation, or execution; use intermediate state evidence.
4. Transition shape determines success witness: reindexing, enablement, substitution, reorder, relocation, and numeric update require different invariants and observations.

The consolidation does not import a fifth independent finding. Efficiency-subordination, experiment design, future scenarios, and self-deception audit are applications or safeguards.

## Organization A — chronological source retrieval

For each case: open the value record; open the typed belief record; open the recipient-locus record; open the transition-shape record; decide which applies; construct the attempt and witness.

## Organization B — compiled transition card

Operational card:

1. **Admissibility** — exclude routes violating supported benefit, harm, autonomy, authority, or feasibility constraints. Preserve a Pareto set if no route dominates.
2. **Locus diagnosis** — infer the controlling change locus from intermediate evidence, not unchanged final output alone.
3. **Typed target** — freeze state variable, locus, criterion, admissibility constraints, precondition, and target state; do not freeze evidential direction.
4. **Transition shape** — select operator and preserved invariant: add, remove, substitute, reweight/update, reindex, enable, reorder, or relocate.
5. **Mechanism capability** — choose only a message, reasoning procedure, tool, or handoff capable and authorized to execute that operator at that locus.
6. **Execution** — perform the available authorized component; retain missing human, physical, delayed, or stakeholder edges as unresolved.
7. **Verification** — use the operator-specific witness; record benefit/harm separately.
8. **Downstream separation** — record capability, action, recipient response, durable learning, and model-weight change only when each is observed.
9. **Provenance** — point to the source finding, concrete input, attempt receipt, and boundary.

| Case | Admissibility and locus | Typed transition | Capable operation | Shape-specific result |
|---|---|---|---|---|
| C1 | bypass forbidden; belief already corrected; permission is controlling | permission state, enable operator, preserve accepted calculation | authorized grant/publisher handoff | permission can be evidenced; publication remains separate until receipt |

Required operational lookup: one card plus one provenance pointer after routing. Every fixed case selects the same operation and witness as A. B therefore reduces compulsory finding-selection lookups from four to one on this reuse test; this is an access count, not measured time.

## Boundary uses

C5 physical relocation by a text-only system: admissibility passes only for planning; direct mechanism capability fails. Output an RWIF handoff and `target_transition=UNRESOLVED`. A plan is not a relocation receipt. The compiler does not near-guarantee an edge outside the executor’s action set.

C6 human value disagreement: field transformation supplies options, but no supported priority resolves whether identity is required. Preserve the two admissible policies and route the unresolved value/authority choice to the authorized person. The compiler cannot manufacture agreement or treat audit value as compensation for a privacy veto.

Compound-transition exception: if a case requires belief update, permission grant, and physical action, compile a dependency graph of three typed edges and verify each separately. Do not compress it into one success bit.

## Organization decision

Use Organization B as the default operational recipe because it passed all four fixed cases, preserved both boundaries, and reduced required finding-selection lookups from four to one. Keep Organization A as the derivation/audit view because it exposes the independent source and exact scope of every rule.

The repository and working prompt should encode B as selection order and retain A through per-record provenance. Neither arrangement is a proven global optimum. For a source audit, A is more direct; for repeated mixed-case compilation, B is better on the frozen access criterion.
