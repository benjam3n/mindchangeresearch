# Reusable findings

The conditions below identify where an existing result can contribute. Each linked record retains its actual case, derivation, and limitations. A constructed case establishes its own consequence; it does not establish a changed human mind.

| Condition | Consequence available for use | Evidence |
|---|---|---|
| An unchanged final action is being treated as an unchanged belief | Intermediate evidence can locate permission, execution, or another controlling dependency; select the contribution that addresses that dependency | [Recipient locus case](../post-allocation/cycle-03/recipient/01-persua-locus-before-message.md) |
| Different kinds of change are assessed using generic content difference | Reindexing can preserve every content field while changing access; enablement and action need separate observations | [Transition shapes](../post-allocation/cycle-03/insight/01-insd-transition-shape.md) |
| Two evidence fields may share an origin | Preserve lineage before aggregation; the copied-alarm case yields `4/13` after counting one originating event | [Evidence dependence](../post-allocation/cycle-02/belief/01-pbr-correlated-evidence.md) |
| A belief direction has been selected before the evidence | Specify the matter and relevant conditions while allowing evidence to determine the revision | [Typed belief transition](../post-allocation/cycle-02/belief/03-araw-8x-transition-first.md) |
| A time-saving operation loses an expiring option | Treat reservation, commitment, and waiting as different operations | [Timing](../gosm/01-time-and-options.md) |
| Two locations contain equally much information | Query-relevant features can still differ; total information alone does not select the useful location | [Location](../gosm/02-location-and-observation.md) |
| A compressed representation will serve another query | Preserved reachability does not entail preserved distance | [Representation loss](../gosm/03-representation-and-loss.md) |
| Feasible actions change | Do not infer a changed preference or motivation merely from a changed feasible set | [Values](../gosm/04-motivation-and-plural-values.md) |
| Equal confidence is used to choose the same next inquiry | The distribution of remaining possibilities can require different questions | [Uncertainty](../gosm/06-uncertainty-and-next-query.md) |
| A complete memory record is difficult to retrieve | Preserve canonical content while indexing the actual use condition; the finite case preserves 48 fields and changes the access route | [Memory access](../post-allocation/cycle-01/memory-capability/01-memk-capture.md) |
| A criterion changes while results are being merged | Retain the earlier result under its original criterion; reevaluation is separate work | [Semantic merge](../post-allocation/cycle-01/tools-coordination/01-col-semantic-merge-protocol.md) |
| Values appear to conflict at the level of one undivided record | Separate content, identity, contact, authority, and expiry so relevant concerns can be served independently | [Field transformation](../post-allocation/cycle-02/values/01-vcd-privacy-auditability.md) |
| More KEEP records are offered as evidence of more benefit | Separate repeated uses, distinct findings, and observed effects | [KEEP-count audit](../post-allocation/cycle-03/motivation/01-sdc-keep-count.md) |
| A complete-looking instruction may still permit useless compliance | Construct materially different realizations that satisfy its wording; supply the missing operation or criterion exposed by the difference | [Prompt countercases](../methods/sp-01.md) |
| A source output enters a different contract | Preserve unknown, optional observations, and activity state as required by the consumer | [54 finite interface cases](../sources/chat-20260908/audit_results.json) |
| A perspective catalog grows through a new dimension | Establish the consequential difference; counting syntactic combinations does not establish added capability | [Historical expansion probe](../sources/chat-20260908/audit_results.json) |
| A correction affects generated content | Revise the generator and inspect its next output; preserve the correction’s applicable scope | [Current intent correction](../research/intent-audit.md) |

The [historical selection card](../post-allocation/cycle-03/consolidation-03-recipe-compiler.md) combines four scoped findings. It remains useful when its conditions hold. [Contribution construction](contribution-construction.md) addresses the operations that the card itself leaves unspecified.
