# Planning and preparation

Candidate contributors describe possible functional relationships. Each source marker supports only its attached statement at the [specified scope](../evidence.md). [Construction](../contribution-construction.md) supplies operations for a particular use.

<a id="target-359"></a>
## 359. Route construction

becoming able to represent a path toward a target.

**Candidate contributors:** Working backward from the target; identifying operations that change required conditions; connecting outputs to later inputs; finding an available first step.

**Conditions and distinctions:** A sequence of plausible activities is not a route unless its dependencies connect to the target.

<a id="target-360"></a>
## 360. Dependency ordering

placing prerequisite activities before their consumers.

**Candidate contributors:** Explicit input requirements; lead times; shared resources; identification of operations that cannot start before another completes.

**Conditions and distinctions:** A visually tidy order can still violate a hidden prerequisite.

<a id="target-361"></a>
## 361. Decomposition

dividing an activity into workable contributions.

**Candidate contributors:** Separating contributions by result; locating interfaces; matching subtasks to usable capability; preserving how their results combine.

**Conditions and distinctions:** Breaking work into smaller pieces can add coordination cost or lose a relation spanning the pieces.

<a id="target-362"></a>
## 362. Coordination

arranging activities so they support rather than obstruct one another.

**Candidate contributors:** Compatible timing; assigned ownership; shared interface meanings; resource conflict resolution; visibility of mutual dependencies.

**Conditions and distinctions:** Locally efficient activities can obstruct one another when their outputs or schedules conflict.

<a id="target-363"></a>
## 363. Contingency construction

preparing different continuations for different conditions.

**Candidate contributors:** Consequential alternative conditions; discriminating indicators; feasible responses; a fallback for an unanticipated state.

**Conditions and distinctions:** Contingencies need resources and authority, not merely labels for possible failures.

<a id="target-364"></a>
## 364. Resource preparation

recognizing and arranging what must be available.

**Candidate contributors:** Inventorying required materials, knowledge, access, time, and collaborators; acquiring or staging missing inputs; reserving constrained resources.

**Conditions and distinctions:** A listed resource contributes only when available in the needed form at the point of use.

<a id="target-365"></a>
## 365. Pacing

changing when and how quickly activity proceeds.

**Candidate contributors:** Task demand; time windows; feedback delay; fatigue and recovery; dependencies on others' timing.

**Conditions and distinctions:** Faster local execution can create downstream waiting, rework, or overload.

<a id="target-366"></a>
## 366. Monitoring plan

deciding what observations should change the plan.

**Candidate contributors:** Identifying observations that discriminate success, failure, or changed conditions; defining what each observation should alter.

**Conditions and distinctions:** Monitoring without a connected decision can consume effort without changing the plan.

<a id="target-367"></a>
## 367. Resumption preparation

making an interrupted activity easier to resume.

**Candidate contributors:** Recording current state, unfinished dependencies, and next action; preserving materials; setting a relevant return cue.

**Conditions and distinctions:** A vague note such as 'continue project' may omit the context needed to resume.
