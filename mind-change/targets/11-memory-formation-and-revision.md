# Memory formation and revision

Candidate contributors describe possible functional relationships. Each source marker supports only its attached statement at the [specified scope](../evidence.md). [Construction](../contribution-construction.md) supplies operations for a particular use.

<a id="target-87"></a>
## 87. Encoding

forming a new memory of an encounter.

**Candidate contributors:** Attention to diagnostic features; relating material to existing knowledge; meaningful organization; active reconstruction during the encounter.

**Conditions and distinctions:** Exposure alone need not encode the relation later needed; meaningful elaboration can also introduce assumptions.

<a id="target-88"></a>
## 88. Retention

changing how long something remains available.

**Candidate contributors:** Retrieval across later occasions; spacing encounters; preserving usable cues; reduced destructive interference; conditions supporting consolidation.

**Conditions and distinctions:** Retrieval and restudy can differ by delay: immediate fluency can favor a method that retains less later [S06](../evidence.md#s06).

<a id="target-89"></a>
## 89. Detail

retaining, recovering, or losing specific features.

**Candidate contributors:** Attention to exact features; accurate external records; discrimination of similar episodes; retrieval that checks specifics rather than only gist.

**Conditions and distinctions:** Repeated retelling can stabilize selected details while losing others.

<a id="target-90"></a>
## 90. Gist

retaining or revising the broader meaning of an event.

**Candidate contributors:** Extracting a common relation; summarizing consequences; integrating an event with prior schemas; later reinterpretation.

**Conditions and distinctions:** A coherent gist can omit an exception that changes the event's meaning.

<a id="target-91"></a>
## 91. Association

linking or unlinking memories with other material.

**Candidate contributors:** Repeated co-occurrence; meaningful relational links; contrast with previously associated material; retrieval in a different context.

**Conditions and distinctions:** Co-occurrence can strengthen an association without showing a causal relationship.

<a id="target-92"></a>
## 92. Updating

incorporating later information into a remembered account.

**Candidate contributors:** New event information; explicit correction of an earlier account; integration with a retained record; identification of what changed.

**Conditions and distinctions:** Later information can contaminate memory for the original event rather than merely supplement it [S07](../evidence.md#s07).

<a id="target-93"></a>
## 93. Forgetting

losing access to or retention of prior material.

**Candidate contributors:** Loss of retrieval cues; competing similar material; disuse or disrupted consolidation; changes in neurological function.

**Conditions and distinctions:** Failure to retrieve does not establish erasure; deliberately withholding use cannot guarantee permanent forgetting.

<a id="target-94"></a>
## 94. Source confusion

changing whether an idea is remembered as observed, inferred, or imagined.

**Candidate contributors:** Separating observation, inference, suggestion, and imagination when recording; preserving original wording and provenance; checking later additions.

**Conditions and distinctions:** Repeated suggestion can alter later reports; labels help only if retained and trusted appropriately [S07](../evidence.md#s07).

<a id="target-95"></a>
## 95. Accuracy

correcting a memory or introducing a distortion.

**Candidate contributors:** Comparison with contemporaneous evidence; correction of a specific discrepancy; maintaining source boundaries; misleading post-event wording that introduces distortion.

**Conditions and distinctions:** Agreement among repeated retellings is not independent confirmation [S07](../evidence.md#s07).

<a id="target-96"></a>
## 96. Emotional association

changing the feeling associated with remembered material.

**Candidate contributors:** New experiences linked to the remembered material; revising its current significance; encountering it in a different emotional context.

**Conditions and distinctions:** Changed feeling does not rewrite the historical event; durable change cannot be inferred from one retelling.
