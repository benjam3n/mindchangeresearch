# Memory accessibility

Candidate contributors describe possible functional relationships. Each source marker supports only its attached statement at the [specified scope](../evidence.md). [Construction](../contribution-construction.md) supplies operations for a particular use.

<a id="target-78"></a>
## 78. Recall

recovering previously unavailable information or experience.

**Candidate contributors:** A distinctive cue; reinstating relevant context; reconstructing associations; narrowing retrieval by time, place, or relation.

**Conditions and distinctions:** A plausible reconstruction may feel like recall; access and accuracy need separate treatment.

<a id="target-79"></a>
## 79. Recognition memory

identifying something as previously encountered.

**Candidate contributors:** Re-exposure to the item; comparison with remembered features; contextual corroboration; discrimination from similar alternatives.

**Conditions and distinctions:** Ease or familiarity can produce false recognition without recollection of the encounter.

<a id="target-80"></a>
## 80. Cue dependence

changing which prompts make a memory accessible.

**Candidate contributors:** Encoding with a later-use cue; retrieving the same content from varied prompts; making the cue-content relation distinctive.

**Conditions and distinctions:** A cue can help only if it connects to a retained representation or supports a valid reconstruction.

<a id="target-81"></a>
## 81. Spontaneous retrieval

a memory becoming available without deliberate search.

**Candidate contributors:** An environmental reminder; associative overlap with current experience; an unresolved concern; emotional or sensory resemblance.

**Conditions and distinctions:** Spontaneous arrival does not reveal whether the remembered content is relevant or accurate.

<a id="target-82"></a>
## 82. Prospective remembering

remembering an intended action when it becomes relevant.

**Candidate contributors:** Linking a specific future event to an action; a visible reminder at that event; rehearsing the event-action pairing.

**Conditions and distinctions:** The event must be detected and the action feasible; a cue-linked plan is not a substitute for ability [S15](../evidence.md#s15).

<a id="target-83"></a>
## 83. Source retrieval

recalling where a representation came from.

**Candidate contributors:** Recording who, where, and when alongside content; source-distinctive cues; comparing the account with the original record.

**Conditions and distinctions:** A content memory can survive while source information is lost; confident attribution can still be mistaken.

<a id="target-84"></a>
## 84. Context retrieval

recovering the circumstances needed to interpret a memory.

**Candidate contributors:** Restoring original circumstances, definitions, purpose, and constraints; a linked contextual record; cues from the surrounding episode.

**Conditions and distinctions:** Recovered context must fit this version of the memory rather than a similar encounter.

<a id="target-85"></a>
## 85. Relevance retrieval

recovering a memory in a situation where it matters.

**Candidate contributors:** Indexing prior knowledge by its application conditions; comparing the current case with an earlier relational structure; a point-of-use retrieval cue.

**Conditions and distinctions:** Surface similarity may retrieve the wrong precedent; consequential conditions must match.

<a id="target-86"></a>
## 86. Retrieval competition

changing which memory comes to mind first.

**Candidate contributors:** Cue specificity; recent retrieval of one candidate; distinctive context labels; separating commonly confused memories.

**Conditions and distinctions:** Making one memory easier to retrieve can leave equally relevant alternatives less available.
