## Correction timing

A correct report can arrive after the action it could have changed is no longer available. Information quality and remaining correction opportunity are separate.

1. Identify the action that a possible observation would change and the latest time that action remains available.
2. Compare the observation's arrival time with that action window.
3. Preserve an option before the window closes when doing so is feasible and consistent with the actual constraints.
4. Record the observed result and the remaining correction separately; later knowledge does not restore an expired opportunity.

The recorded time case changes the report from 09:15 to 09:25 when action A must begin by 09:20. Waiting for the later report cannot preserve that start opportunity. Reserving or beginning an available action must be assessed against its own consequences.

The source supplies a constructed timing comparison. It does not establish a universal rule to act early or to interrupt every uncertainty.
