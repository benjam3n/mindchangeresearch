# Values

## Separate value conditions

An apparent tradeoff can be produced by bundling together fields that serve different concerns. Separating the fields can change the available alternatives.

1. State each actual concern and the condition it requires, preserving constraints that cannot be exchanged for unrelated benefits.
2. Separate the affected object into the fields those conditions concern.
3. Construct combinations that preserve required fields while changing the source of conflict.
4. Retain an unresolved choice when the conditions still conflict; do not turn a new option into an assertion that the person's values changed.

The recorded audit/privacy case separates dissent content, identity, contact route, decision authority, and expiry. Publishing the required content while withholding unnecessary identity can satisfy the stated case without trading privacy against a larger audit score.

A field-level arrangement is demonstrated in the constructed case. Human value change and acceptance by a real stakeholder remain unobserved.
