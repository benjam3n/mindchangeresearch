# Disagreement

## Claim comparison

Identical facts can support different priorities; identical words can express different claims. The disagreement is not identified until the conflicting commitment is located.

1. State each position using the same subject, period, reference class, and meanings where the speakers actually intend them.
2. Retain differences in meaning rather than silently imposing one definition.
3. Separate disputed facts from differing goals, priorities, permissions, and proposed methods.
4. Direct the next contribution to the remaining disagreement; additional evidence addresses a factual dispute only when that dispute remains live.

Two people can accept the same alarm calculation while disagreeing about who may publish it. Repeating the calculation addresses neither the authorization question nor the disputed arrangement of decision power.

The source exercises this distinction in a constructed publication case. Human agreement and subsequent publication are separate observations.
