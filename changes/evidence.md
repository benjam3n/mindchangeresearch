# Evidence

## Event provenance

Two reports copied from one event supply one event's evidence. Two different authors do not establish two independent observations.

1. Associate each report with the observation it actually derives from; retain unknown ancestry as unknown.
2. Collapse deterministic copies into the same observation without deleting their provenance.
3. Use one likelihood contribution for each distinct event only where its joint or conditional-independence assumptions are supplied.
4. Apply the decision threshold after the evidential calculation; preserve uncertainty when the dependence model is missing.

The existing alarm example specifies prior 0.10, sensitivity 0.80, and false-positive rate 0.20. Two copies of one HIGH event yield 4/13. Two HIGH events conditionally independent under both defect and no-defect hypotheses yield 16/25. Under the stipulated rule to replace when the posterior exceeds 0.50, the first case selects inspection and the second selects replacement.

Exact calculation within the stipulated model, already exercised in the source record. No empirical calibration of an actual sensor is supplied.

## Discriminating observations

An observation that every remaining explanation predicts cannot separate those explanations. Additional reports can leave the actual uncertainty untouched.

1. Write the competing explanations as distinct claims about the same event and conditions.
2. For each available observation, state the different result each explanation predicts; preserve missing predictions rather than inventing them.
3. Choose an obtainable observation whose possible results separate the live alternatives relevant to the decision.
4. Revise only the alternatives contradicted or supported by that result; weakening one explanation does not establish its rival.

If both 'belief remains disputed' and 'belief is accepted but publishing permission is absent' fit nonpublication, another observation of nonpublication does not distinguish them. The person's accepted calculation and the permission record answer different unresolved questions.

The permission-versus-belief distinction was exercised on constructed cases. Obtaining a person's actual belief or permission still requires the relevant evidence.
