# Understanding

## Contrasting cases

Knowing a rule includes distinguishing a case it governs from a near match it does not govern. Repeating its wording leaves that distinction unexamined.

1. Express the rule as an explicit condition and its consequence.
2. Keep the rule's consequent and all other supplied facts fixed while changing one condition from present to absent.
3. Apply the rule to both cases and identify the changed condition that accounts for the different answers.
4. Change a surface feature while preserving that condition; apply the rule again. An unchanged relevant condition should preserve the answer within the rule's stated scope.

For the stipulated rule 'rebuild the index before rollback when the schema has advanced,' a checksum mismatch alone does not establish the prerequisite. Adding 'schema advanced' requires rebuilding first. A changed person's name supplies neither a changed schema nor permission to act.

The stored retrieval case supplies the conditional and a constructed transfer. The contrasting-case procedure is a proposed extension; human acquisition and retention have not been observed.

## Independent reconstruction

A supplied answer and the ability to produce it under changed conditions are different capacities. The missing operation becomes visible when the conclusion is withheld.

1. Retain the problem's premises and remove the worked conclusion from the material supplied for the next attempt.
2. Produce the missing dependency, calculation, or classification before revealing the reference result.
3. Compare the attempted transitions with the premises; identify the earliest unsupported transition rather than replacing the whole attempt with the answer.
4. Repeat on a changed input requiring the same dependency, preserving any boundary that changes the valid operation.

With prior odds 1/9 and one independent likelihood factor of 4, reconstruct odds 4/9 and probability 4/13. With two conditionally independent factors, reconstruct 16/25. Displaying the second answer beforehand would turn this into recognition.

The arithmetic follows from the supplied finite model. Context-isolated learning or delayed retention is not established by generating another answer in the same conversation.
