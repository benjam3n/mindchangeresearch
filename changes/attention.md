# Attention

## Attention selection

A visible item and an item governing the next operation are different. Keeping all material in the record does not require processing all of it at once.

1. Name the question being answered and the observations that could alter its answer.
2. Separate those observations from material that cannot alter this answer under the supplied conditions.
3. Keep the original material accessible while placing the relevant subset in the next working view.
4. Answer from that subset, then check whether an excluded condition changes the answer; restore such a condition if it does.

In the existing finite case, the working set changes from {A,B,C} to {B}. The change succeeds as an artifact operation only if B remains available, A and C leave the active view, and no required dependency is lost. The record itself need not delete A or C.

Finite selection and preservation criteria are supplied. A changed model input is not an observation of human attention.
