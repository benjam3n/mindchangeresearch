# Perception

## Query and representation

Two representations can preserve the same facts while exposing different relations. The question determines which loss matters.

1. List the actual questions the representation must answer.
2. Answer them from the original representation before compressing or rearranging it.
3. Construct the alternative and repeat those same questions.
4. Keep the preserved answers and disclose changed answers; a reachability-preserving transformation need not preserve distance.

The existing graph example reduces 28 edges to seven while preserving 56 reachability answers and changing 21 distances. It is adequate for those reachability queries and inadequate as a distance-preserving replacement.

The source reports the finite graph comparison. It does not demonstrate a change in a human sensory system.
