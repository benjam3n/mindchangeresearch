# Mind changes

For the complete inherited contributor inventory, use [590 human and 26 functional AI targets](../mind-change/targets.md), [contributor construction](../mind-change/contribution-construction.md) and the [required Subject Systems](../mind-change/subject-systems.md). The shorter map below connects selected practical routes and foundational inquiries to that broader work.

These entrances overlap. They are a map of available work and missing demonstrations, not a complete division of minds. An encounter may change the labels, create a new concern, or reveal that several rows describe one activity.

“Constructed case” means the inputs were stipulated and consequences derived or computed. “Design” means a proposed route whose relevant effect has not been observed. A source record's completion status is separate from these evidential limits.
