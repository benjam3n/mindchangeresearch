A configuration through which specified differences become consequential for an entity or interaction.

| Type | Description |
|---|---|
| Perspective bearer | The entity or interaction to which the configuration is attributed. |
| Perspective disposition | A capacity to respond differently under specified interaction conditions. |
| Perspective regulation | A configuration relating detected differences to changes in an ongoing process. |
| Perspective interpretation | An operative interpretation that makes particular distinctions, concerns, and responses relevant. |
