| Property | Description |
|---|---|
| Condition | Different perspectives supply necessary contributions, but no one supplies the whole required result. Their outputs may also conflict or use incompatible assumptions. |
| Operation | Treat the perspectives as contributors to an arrangement. State each contribution, required input, scope, and commitment; order dependencies; specify how a result changes the next contributor's input or adoption condition; retain incompatibilities; identify what the combined arrangement adds and where it can fail. |
| Subject | Reasoning approach composition, System design composition, and System composition order dependence |
| Result | a defined arrangement with a traceable use for each contribution. |
| Applicability | Scope, assumption, and operation conflicts can impair the composition. |
