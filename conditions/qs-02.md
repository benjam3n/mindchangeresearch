Concrete finite queue: A releases at 0, takes 4 units, and is due at 7. B releases at 1, takes 2, and is due at 3. Work is nonpreemptive on one processor. The exact consequence of two queue disciplines is calculated from these declared inputs.

| Route | Sequence | Finish A | Finish B | Meets both deadlines? |
|---|---|---|---|---|
| Start available work immediately | A 0–4; B 4–6 | 4 | 6 | No |
| Reserve upcoming urgent window | idle 0–1; B 1–3; A 3–7 | 7 | 3 | Yes |

The queue objective is meeting both deadlines. One unit of purposeful idle time creates the only contiguous B interval ending by 3 while leaving four units for A. A priority queue over currently ready work is insufficient: at 0 it sees only A. Priority must include the known upcoming release constraint.

Eight varied conditions show the boundary. If B releases at 2, its earliest finish is 4 and its deadline is already impossible; waiting does not fix it. If B takes 1, an alternative schedule may gain slack. If A is preemptible, start A 0–1, run B 1–3, finish A 3–6. If B’s release is speculative, reserving time has uncertain value. If A’s deadline is 6, the nonpreemptive waiting route fails A. If A takes 3, both can fit with B first by 6. If no B arrives, the pause has only delay cost. If switching itself takes one unit, the schedules need that extra duration and cannot reuse these results unchanged.

Selected discipline for the given inputs: reserve 0–1, B first on release, A second. A finite validator will check start≥release, finish=start+duration, no overlap and finish≤deadline before the route is used in the transfer application. Starvation prevention here is a protected post-B slot for A; this is a two-job guarantee, not a general policy over unbounded arrivals.

This case directly challenges unqualified “never leave the bottleneck idle” or “do available work now” instructions. It does not challenge those rules under all-ready, preemptible, or no-future-information assumptions. The pause changes timing and available action, not the worker’s confidence or motivation.
