# LAYER 2 — THE UNEXPECTED

## Candidate U1 — Transition-first response competition

Core idea: Before choosing a skill or drafting an answer, instantiate competing direct changes at different loci: change the environment or tool constraint; change the available action; change the representation; change attention; change the queried belief; change emotional appraisal; or leave the state unresolved. Select the smallest candidate whose causal route to the stated benefit is supported and authorized. Invoke a reasoning skill only for an unresolved search, derivation, or verification inside that candidate.

Why it works on the frozen coordination case: The target failure is a silent incompatible merge. A response that explains provenance or analyzes coordination still leaves the merge operation permissive. The tool-state candidate makes `criterion`, `outcome`, `provenance`, and `evidence_status` versioned fields; rejects `r1` when criterion versions disagree; retains `r2`'s provenance as a required field; and leaves `r3` gated when evidence is absent. It reaches the specified artifact state without depending on a person remembering the explanation during every merge.

What is non-obvious: The selected object is not a method, argument, document, or belief. It is a prospective state transition at the most proximal controllable locus. Original procedures become callable resources rather than the architecture's starting node.

Quality gate: PASS within model response selection. It is structurally different from skill-first execution; the field-level gate is feasible; it addresses the frozen merge need; and it complements rather than weakens the current evidence method. Human benefit remains untested.

## Candidate U2 — Failure-triggered method activation

Core idea: Begin with the shortest direct candidate response. Activate a Reasoningtool procedure only when a named failure is present: unresolved target, missing distinction, unsupported inference, inadequate alternatives, disputed values, unavailable evidence, or unsafe irreversibility. A response with no such failure ends without a skill application.

Why it might work: A direct checksum command does not become more beneficial merely because multiple complete reasoning procedures surround it. The current source and verification controls remain available when the direct candidate crosses a failure trigger.

What is non-obvious: Procedure execution becomes conditional exception handling rather than the normal production path.

Quality gate: UNRESOLVED. It is structurally different and potentially efficient, but the frozen corpus supplies no latency or error comparison showing that the trigger set catches every case in which a skill changes the answer. It cannot replace the strong current method on present evidence.

## Candidate U3 — Competing recipients inside one response

Core idea: Treat the environment, interface, future self, collaborator, and current user as separate possible recipients. Direct each required change to the recipient that can enact it most reliably: encode repeatable constraints in the tool, attach exceptions to the record, reserve human-facing text for genuine choice, and avoid asking memory to carry machine-checkable invariants.

Why it might work: In the coordination case, the merge tool receives the incompatibility rule, the record receives provenance, and the human receives only the remaining choice. The same content is not broadcast to every recipient.

What is non-obvious: “Who should this sentence persuade?” is replaced by “Which system component can make this transition true?”

Quality gate: PASS as a complement. It produces the same required artifact protections as U1 while additionally allocating content by recipient. Its independent advantage over U1 is not measured, so it is retained as an alternative organization rather than a second novelty claim.

# LAYER 3 — THE REFRAMED

The problem is not primarily how to make reasoning outputs better at changing minds. The frozen target contains changes that do not require persuasion and changes that should not be assigned to a human mind at all. A missing provenance field is better changed in the record schema; a recurring invalid merge is better changed in the merge permission; a safety query is better changed by inspection location; an ambiguous quantitative answer is better changed by naming the sampling measure. The operative question is: **which state must become different, at which locus, through which shortest supported causal route?** “Choose the reasoning technique” is a downstream question that occurs only when that route contains unresolved reasoning.

This does not eliminate belief, motivation, emotion, or memory interventions. It rejects their automatic priority. When the target itself is a belief and the evidence is available, belief is the correct locus. When the contributor's appraisal is unobserved, the response may alter message content but cannot report an emotional change.

# DISRUPTIONS APPLIED

1. First-answer rejection: retained skill-first execution as the baseline and refused to stop there.
2. Assumption elimination: removed “a research contribution begins by choosing a skill” while retaining source and evidence requirements.
3. Domain transfer: transferred constraint enforcement from type systems and transaction validation—invalid combinations are unrepresentable or rejected—into coordination response selection.
4. Trade-off resolution: preserved rigorous procedure access while avoiding mandatory procedure execution for every direct state change; procedures are invoked inside the selected transition when needed.

# STRUCTURAL DIFFERENCE CHECK

Layer 2 differs from Layer 1 because Layer 1 selects a reasoning procedure and then seeks its useful consequence, whereas U1 selects a prospective state transition and calls a procedure only inside unresolved parts of its causal route.

Layer 3 differs from both because it changes the problem from producing mind-changing reasoning to locating the state and system component that should change. A response can therefore succeed by altering a tool constraint, representation, location, timing, or available action without claiming a changed belief.

Conventionality check: Direct environment design and type-safe validation are familiar within their own fields. Their use as the first selector across the entire stated mind-change target, before reasoning-method selection, is not established in this corpus. The candidate is non-obvious relative to the current skill-by-skill architecture, not claimed novel to all experts or fields.
