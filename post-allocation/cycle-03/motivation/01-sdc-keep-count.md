# SDC 8x — a large KEEP count is not evidence of a beneficial cycle

Intended mind change: Stop treating many favorable self-verdicts as evidence that a research cycle produced genuine beneficial mind changes.

Actual starting judgment: A cycle with many KEEPs probably performed well.

Concrete input: cycle 01 reported 12 scoped KEEPs reduced to seven distinct findings; cycle 02 reported nine scoped KEEPs reduced to three distinct findings; the frozen claim is “many KEEPs show the cycle is beneficial.” This is Interpretation 3, a recurring-pattern audit of self-evaluation.

## Section A — pre-decision check: ten tests

Current leaning: accept a cycle as beneficial when most records say KEEP. Certainty before audit: 6/10. The leaning arose after seeing high KEEP totals.

| Test | Observed answer | Flag |
|---|---|---|
| A1 opposite-cycle test | identical methods labeled UNRESOLVED would feel less successful | yes: label sensitivity |
| A2 evidence balance | supportive verdict count exceeds independent outcome evidence | yes |
| A3 strongest contrary case | 12 KEEPs collapsed to seven distinct | yes |
| A4 symmetric standard | a rival system’s self-issued KEEPs would not suffice | yes |
| A5 precommitment | novelty rules existed before cycle 02, not before every earlier record | mixed |
| A6 falsifier | duplicated finding or failed later use would reduce benefit claim | passes: falsifiable |
| A7 stakes | rejecting the count weakens a visible progress story | yes |
| A8 source substitution | source fidelity does not establish beneficial result | yes |
| A9 outcome substitution | polished document does not establish user change | yes |
| A10 delay test | several human/delayed effects remain unobserved | yes |

Pre-decision result: high risk of conflating bookkeeping success with benefit. No bodily/emotional state is claimed because none was observed.

## Section B — post-decision audit: ten tests

The prior decision was to retain all scoped KEEPs while separately deduplicating them. Reasons appeared after documents were produced, so retrospective justification risk is real.

| Test | Result |
|---|---|
| B1 timeline | outputs preceded integration verdicts |
| B2 reason removability | removing novelty would change the cumulative finding count |
| B3 real-reason candidate | a high number makes the run look productive; candidate only, not attributed motive |
| B4 substitution | an outside project’s self-ratings would require independent checks |
| B5 update symmetry | null and rejected records were preserved, improving symmetry |
| B6 sunk-work test | long records were not automatically counted distinct |
| B7 source/procedure split | source match and procedure completion remained separate |
| B8 benefit/procedure split | local benefit and human outcome remained separate |
| B9 later-use test | some findings changed later operations; others did not |
| B10 reversal condition | four verifier failures would reverse the benefit verdict |

Post-decision result: the separate novelty review is justified, but “many KEEPs” is not.

## Section C — recurring-pattern audit: ten tests

| Test | Pattern evidence |
|---|---|
| C1 recurrence | favorable verdicts recur across method families |
| C2 common trigger | each procedure is asked to produce a useful attempt |
| C3 common payoff | KEEP supports continuation and visible progress |
| C4 common blind spot | self-assessed local utility is easier to observe than recipient effect |
| C5 exception | GOSM 05 rejected its benefit claim despite a complete procedure |
| C6 exception | ARAW rejected the unqualified universal while keeping a scoped repair |
| C7 dependency gate | SATRDA stayed partial because its required clarity dependency was unavailable |
| C8 delayed gate | human and reader effects remain partial rather than promoted |
| C9 dedup pattern | cycle 01: 12→7; cycle 02: 9→3 |
| C10 interruption rule | do not infer benefit from count; require verifier-level evidence |

Pattern result: the system has corrective exceptions, but its raw KEEP total is structurally inflated by refinements and later uses.

## Five lookbacks

1. Cycle 01: 12 scoped KEEPs became seven distinct findings after novelty review.
2. Cycle 02: nine scoped KEEPs became three distinct findings after novelty review.
3. ACR: procedure/use was kept while durable learning stayed unobserved.
4. SATRDA: useful work stayed partial because a named dependency was unavailable.
5. GOSM 05: complete routing exercise received a rejected benefit claim rather than automatic KEEP evidence.

## Four independent verifier types

| Verifier | Concrete operation | Current result |
|---|---|---|
| arithmetic/counterexample | recompute a result or apply a changed case | some KEEPs change decisions; count itself predicts nothing |
| source/dependency | compare original requirements and preserve missing inputs | exposes complete, partial, and blocked distinctions |
| novelty/deduplication | compare mechanism and demonstrated consequence | 21 scoped KEEPs became 10 distinct findings across cycles 01–02 |
| later-use observation | show a later operation changed because of the finding | present for some findings; absent for many human outcomes |

Decision rule: a cycle benefit claim may cite verified distinct findings, repaired errors, avoided failures, and demonstrated later uptake. It may not cite the raw number of KEEP labels as sufficient evidence.

## Outcome

Actual mind change: I changed from “high KEEP rate probably means beneficial” to “KEEP is a scoped disposition; benefit requires an external verifier appropriate to the claimed consequence.”

Benefit or harm: This audit prevents 21 favorable labels from being reported as 21 distinct discoveries and retains counterevidence. It does not determine human benefit where no human observation exists.

Verdict: KEEP for the audit; REJECT the frozen inference. Original 8x floors met: three sections, ten tests per section, five lookbacks, and four verifier types.

Content assessment: Motivation is treated as an alternative explanation candidate, not invented internal fact. The conclusion rests on count collapses and gate preservation.

Organization assessment: `record verdict → novelty class → verifier → claimed scope → later uptake` is more diagnostic than a KEEP total.

Next attempts: Blind a reviewer to verdict labels; measure inter-rater novelty agreement; predefine a benefit threshold; test a cycle with few but high-impact findings; observe recipient outcomes.
