# Mind change

Develop useful, efficient ways to change what a mind can notice, understand, care about and do, including the conditions, aims and standards through which those possibilities arise. The starting account can lose its governing authority without first becoming false.

A worthwhile intended change, a procedure that can produce it, and an executor able to perform it are separate requirements. A statement, a modification operation, a usable recipe, and an observed effect are different contributions.
